# 🏎️ Kocur Kart

Závodná hra pre Windows postavená v **Godot 4**. Cieľ: vydanie v **Microsoft Store** (MSIX).

> 🚧 Projekt práve začína. Herný dizajn a plán sa doplnia podľa detailného zadania.

## 📁 Umiestnenie

Kocur Kart je samostatný Godot projekt v podpriečinku repozitára `Kocur-Neon-Heist`.
Má vlastný `project.godot`, takže sa otvára samostatne:

- Godot → **Import** → vyber `KocurKart/project.godot`

Hlavný projekt **Kocur: Neon Heist** v koreni repozitára tento priečinok ignoruje
(Godot preskakuje vnorené projekty a export Neon Heist má `KocurKart/*` vo `exclude_filter`).
