KOCUR KART  v1.0.0
Arcade kart racing by Kocur Studios

HOW TO PLAY
  1. Unzip the whole folder anywhere (for example to your Desktop).
  2. Double-click KocurKart.exe.
  No installation, internet connection or account is needed.

CONTROLS (keyboard)          GAMEPAD
  W / Up      Accelerate      RT or A
  S / Down    Brake/Reverse   LT or B
  A D / <- -> Steer           Left stick / D-pad
  Space       Drift (hold)    RB
  Shift       Purr Boost      X or LB
  R           Recover kart    Y
  Esc / P     Pause           Start
Keys can be rebound in Settings > Controls.

DRIFT & BOOST
  Hold Drift while steering into a corner. Blue sparks = small boost,
  orange sparks = big boost - release Drift to fire it. Every boosted
  drift fills the Purr meter; press Purr Boost to spend a full segment.
  Press Accelerate while "1" is showing on the countdown for a perfect start.

MINIMUM REQUIREMENTS (estimated)
  Windows 10/11 64-bit, OpenGL 3.3 capable GPU (integrated GPUs from 2015+),
  4 GB RAM, 300 MB disk space.

SAVE DATA
  %APPDATA%\KocurKart\   (save.json, settings.cfg, Time Trial ghosts)
