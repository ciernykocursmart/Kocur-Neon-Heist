KOCUR: NEON HEIST - v1.0.0 - Windows x86_64

A neon stealth/action heist about a small cybernetic cat.
12-mission campaign in three acts + Endless Heist mode.

HOW TO RUN
  Unzip anywhere and run KocurNeonHeist.exe. No installation needed.
  Requires a GPU with OpenGL 3.3 support.
  The build is not code-signed yet, so Windows SmartScreen may ask you to
  confirm ("More info" -> "Run anyway").

SAVE DATA
  %APPDATA%\KocurNeonHeist\  (written atomically, with a backup copy)

CONTROLS
  WASD move | Mouse aim | LMB fire | R reload | 1/2/3, wheel or Q weapons
  RMB/F claw (silent takedown from behind) | Space dash | Shift sneak
  E hack / interact | G yarn decoy | Esc pause

All art, sound and music are generated procedurally by the game.
Built with Godot Engine (MIT licence, https://godotengine.org/license).
