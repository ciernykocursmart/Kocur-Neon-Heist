KOCUR: NEON HEIST - Windows x86_64 prototype build (v0.1.0)

Run KocurNeonHeist.exe. No installation needed (single self-contained file).
Requires a GPU with OpenGL 3.3 support (virtually every PC from the last decade).
The build is not code-signed, so Windows SmartScreen may ask you to confirm
("More info" -> "Run anyway").

Save data: %APPDATA%\KocurNeonHeist\

Controls: WASD move, mouse aim, LMB fire, R reload, RMB/F claw takedown,
Space dash, Shift sneak, E hack/interact, Esc pause.
