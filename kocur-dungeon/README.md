# Kocur Dungeon

A complete 2D pixel-art action platformer by **Kocur Studios**, made in **Godot 4.3**
for **Windows x64**. You are Kocur, a small black cat. The white-cat clan of the Pale
King has stolen ten of your friends. Fight through five regions, rescue the captives
and defeat the Pale King.

Everything in the game (code, pixel art, animations, the pixel font, sound effects and
music) was made for this project. The art and audio are generated by the Python scripts
in `tools/`; the generated files are committed, so the game runs without Python.

- Download the Windows build: `KocurDungeon-windows-x86_64.zip` (built by `tools/build_windows.sh`;
  binaries are not committed to git).
- Test results: [TEST_REPORT.md](TEST_REPORT.md)
- Manual QA checklist for KX: [KX_TEST_CHECKLIST.md](KX_TEST_CHECKLIST.md)
- Progress and known issues: [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md), [CHANGELOG.md](CHANGELOG.md)

## Playing

Unzip the ZIP and run `KocurDungeon.exe`. No installation or internet needed.
Windows may show a SmartScreen warning because the exe is not code-signed
("More info" -> "Run anyway").

| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move | A / D or Left / Right | Left stick / D-pad |
| Jump (hold = higher) | Space | A |
| Claw attack | J or Left mouse | X |
| Pounce (hold Up = upward pounce) | K or Right mouse | B / RB |
| Drop through thin platform | hold S / Down + Space | Down + A |
| Interact (doors, cages, levers) | E | Y |
| Pause | Esc | Start |

Saves live in `%APPDATA%\KocurDungeon\` (`save.json`, `settings.cfg`).

## The game

**Campaign:** 5 regions x 3 levels plus the final encounter (16 levels). Level 1-1
teaches the controls with signs. Every level has a start, a checkpoint lantern, an exit
door, coins, Shadow Gems, secrets, and most have a caged cat.

| Region | Levels | New ideas | Guardian |
|---|---|---|---|
| 1 Mossroot Catacombs | 1-1 Mossy Steps, 1-2 Root Hollow, 1-3 The Iron Gate | jumping, claws, pounce, crumbling stones, fake walls, levers & gates | **The Iron Mouser** (slam + shockwaves, charge, phase 2 leap) |
| 2 Emberpaw Mines | 2-1 Cinder Shafts, 2-2 Bellows Deep, 2-3 The Forge Heart | lava, flame jets, moving lifts, guards, archers | **The Ember Guardian** (hammer smash fire waves, fireball volleys, phase 2 erupting floor) |
| 3 Frostfang Crypt | 3-1 Rime Gallery, 3-2 Icicle Vaults, 3-3 Matron's Hall | slippery ice, falling icicles, springs, mages | **The Frost Matron** (blink, shard fans, icicle rain, phase 2 nova) |
| 4 Shadowclaw Depths | 4-1 Lightless Way, 4-2 Hollow Echoes, 4-3 Stalker's Den | darkness and torches, beasts, hidden passages | **The Shadow Stalker** (leaps, vanish & rush, phase 2 shadow orbs) |
| 5 Pale King's Citadel | 5-1 Marble Ramparts, 5-2 Hall of Banners, 5-3 The Bell Tower, The Pale Throne | saws, every enemy type, a climb chased by rising pale fire | **The Pale King** - 3 phases: Royal Duel, Court of Light (teleports, orb rings, light pillars, summons), Pale Fury (crown shards, faster combos) |

**Enemies (5 archetypes):** White Scout (patrol, chase, dagger lunge), White Guard
(shield blocks claws from the front, telegraphed spear thrust), White Archer (keeps
distance, draws then fires aimed arrows - claw them away), White Mage (orb volleys,
rune traps that mark the floor first, blinks away), White Beast (roars, charges, gets
stunned on walls, stomp shockwaves). Every attack has a wind-up or a warning sign.

**Combat:** claw (one hit per swing per enemy, cooldown, knockback, hit-stop, can deflect
projectiles) and pounce (dash with brief invulnerability, cooldown bar in the HUD, bounces
off enemies, upward variant). Health is in half-hearts; i-frames after a hit; fish heal.
Guardians have health bars, phases and vulnerable windows after big attacks.

**Progression:** coins buy 7 permanent upgrades at camp (Nine Lives Charm, Razor Claws,
Spring Paws, Heavy Pounce, Fishmonger's Recipe, Thick Fur, Whisker Sense; some need
Shadow Gems). Each of the 10 rescued cats gives a permanent perk (extra heart, shop
discount, coin bonus, half hazard damage, faster pounce, healing checkpoints, secret walls
shimmer, fish drops, starting shield) and sits by the campfire. Between levels you choose
one of three temporary **blessings**, lost when you return to camp. Optional challenges per
level (all secrets, all gems, no deaths, guardian without eating fish) pay coins once.
Level select with medals, records, completion percentage and an ending with statistics.

**Difficulty:** Assist (half damage), Normal, Hard (+50% damage), in Settings.
**Settings:** master/music/effects volume, fullscreen, window size (1280x720, 1600x900,
1920x1080, 2560x1440), difficulty, screen shake, controls page, reset progress.

## Project layout

```
kocur-dungeon/
  project.godot, export_presets.cfg, icon.svg, LICENSE_GODOT.txt
  scenes/                 main_menu, camp, level, ending (thin .tscn, built in code)
  scripts/autoload/       settings, save_manager, progression (Progress), audio_manager, transition
  scripts/player/         player.gd (controller + states), player_combat.gd, movement.gd (shared constants)
  scripts/enemies/        enemy_base.gd + scout, guard, archer, mage, beast, projectile, rune
  scripts/bosses/         boss_base.gd + iron_mouser, ember_guardian, frost_matron, shadow_stalker, pale_king
  scripts/world/          level.gd (level manager), level_grid.gd (map parser), tile_renderer.gd
  scripts/objects/        checkpoint, exit door, pickups, cage, chest, lever, gate, platforms, hazards...
  scripts/ui/             ui_kit, hud, pause_menu, settings_panel, level_overlays, main_menu, camp, ending
  scripts/data/           game_data (upgrades, cats, blessings), level_catalog, maps/region1-5.gd (generated)
  scripts/fx/             sprites (sheet slicing), fx (particles, floating text)
  assets/                 sprites/, audio/, fonts/ (generated, committed)
  tests/                  run_tests.gd, test_case.gd, suites/*.gd, level_reach.gd (reachability validator)
  tools/                  gen_art.py, gen_art2.py, gen_audio.py, mapkit.py, build_maps.py,
                          run_tests.sh, build_windows.sh, pack_smoke.gd
```

Levels are written as ASCII maps with a small Python DSL in `tools/build_maps.py`
(legend in `scripts/world/level_grid.gd`) and generated into `scripts/data/maps/`.

## Developing

Requirements: Godot 4.3 stable (and its export templates for building), Python 3 with
Pillow and NumPy only if you want to regenerate art/audio/maps.

```bash
godot --path kocur-dungeon                      # run / edit
python3 tools/build_maps.py                     # regenerate level maps after editing the DSL
python3 tools/gen_art.py; python3 tools/gen_audio.py   # regenerate art / audio
godot --headless --path . -s res://tests/reach_report.gd -- 2-1   # reachability report for a level
tools/run_tests.sh                              # full automated test suite
tools/build_windows.sh                          # Windows x64 export + ZIP + exported-pack smoke test
```
